# A股首板初筛量化系统

把一套“**首板打板**”短线交易体系量化成可执行的 Python 代码：
**首板初筛（七大一票否决）→ 强中择优（锁定 2~3 只自选）→ 次日博弈（集合竞价观察 + 打板进场）**。

---

## 一、数据源选型

采用 **[akshare](https://akshare.akfamily.xyz/)**（免费、开源、无需 token / 积分）作为 A 股数据源，理由：

- 直接提供东方财富**「涨停股池」** `stock_zt_pool_em`，一次返回当日全部涨停股及
  **炸板次数、流通市值、换手率、封板资金、首次/最后封板时间、连板数、所属行业**
  —— 七大否决条件的大部分字段一步到位；
- 配套覆盖日线、分时、集合竞价等接口，支撑“强中择优”和“次日进场”。

实际使用的接口（均已在本仓库联网验证可用）：

| 用途 | 接口 | 说明 |
|---|---|---|
| 当日首板候选 + 多数否决字段 | `stock_zt_pool_em` | 东财涨停股池，`连板数==1` 即首板 |
| 日线历史（半年涨停数 / 前期涨幅 / 一字板） | `stock_zh_a_hist_tx`（腾讯）→ `stock_zh_a_hist`（东财）回退 | 双源互备 |
| 分时（炸板确认 / 拉升量价 / 放量尖峰） | `stock_zh_a_hist_min_em` | 1 分钟线 |
| 次日集合竞价（09:15–09:25） | `stock_zh_a_hist_pre_min_em` | 含竞价撮合 |
| 盘中实时盘口（打板信号） | `stock_bid_ask_em` | 仅交易时段可用 |

> 数据访问层 `first_board/datasource.py` 对每个接口都做了 **重试 + 指数退避 + 多源回退**，单点不可用自动切换。

## 二、策略 → 代码映射

### 核心交易准备 ①：首板初筛（七大“一票否决”）
收盘后复盘当日全部首板，命中任一条即剔除（`first_board/screening.py`）：

| # | 否决条件 | 量化判据 | 默认阈值 |
|---|---|---|---|
| ① | 分时走势弱（反复炸板） | `炸板次数 ≥ N` | N=2 |
| ② | 盘子过大 | `流通市值 > 100 亿` | 100 亿 |
| ③ | 股性不活跃 | 近半年(120 交易日)涨停次数 `< 2` | 2 次 |
| ④ | 绝对价格高 | `最新价 > 20 元` | 20 元 |
| ⑤ | 缺乏换手（一字板） | 当日 `开=高=低=收` 涨停 **或** 09:25 封板且换手极低 | — |
| ⑥ | 位置过高 | 首板前 60 日涨幅 `> 50%` | 50% |
| ⑦ | 单打独斗（无板块效应） | 同“所属行业”当日另有涨停 `< 1` 只 | 1 只 |

涨停幅度按板块自动取 **10%/20%/30%**（主板/创业·科创/北交所）。

### 核心交易准备 ②：强中择优（`first_board/ranking.py`）
对通过初筛者按三维度打分排序，取前 `top_n`（默认 3）：

1. **封板时间**：越早越好（早盘最佳）。
2. **量价配合**：换手落在理想区间（默认 5%~25%）；**过分高开后的秒板**扣分。
3. **封板力度**：以 **封成比 = 封板资金 / 流通市值** 为主，叠加分时首封时刻**放量尖峰**二次确认。
   > “封板瞬间扫单买量”严格需要 Level-2 / 逐笔成交数据；免费源仅有静态封单，故用封成比 + 分时放量代理。已预留 `seal_burst_from_tick()` 升级接口，接入逐笔后可平滑替换。

### 实战进场节点：次日博弈（`first_board/entry.py`）
- **集合竞价观察**：理想高开 **3%~5%**，且竞价换手率 ≈ 昨日全天换手率的 **10%**（有资金抢筹）。
- **唯一进场信号——打板**：绝不盘中追涨；只在资金扫货、**即将封死涨停**的瞬间挂涨停价。
  “先涨停、先符合条件，就打谁。”

## 三、安装与使用

```bash
pip install -r requirements.txt
```

```bash
# 复盘某交易日首板，输出自选池
python run_screening.py --date 20260530

# 快速模式（跳过依赖日线历史的 ③⑤⑥ 判定）
python run_screening.py --date 20260530 --no-history

# 顺带做次日集合竞价检查（需在次日盘前/盘中运行）
python run_screening.py --date 20260530 --auction
```

作为库调用：

```python
from first_board import run_pipeline
out = run_pipeline("20260530")        # 首板当日 YYYYMMDD
print(out.summary())
for pick in out.watchlist:            # 锁定的 2~3 只自选
    print(pick.code, pick.name, pick.score)
```

全部阈值集中在 `config.py`，可按风格自由调参。

运行单测（纯逻辑、不联网）：

```bash
pytest -q
```
